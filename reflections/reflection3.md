## Reflection Questions

* Name at least one successful thing this week.

We added the ability for users to search for other users and use their information to prepopulate the form.

* What were some challenges you and/or your group faced this week?

We struggled with deployment. While our program worked locally, when we put the application on Render, we found that our features oftentimes did not work, sometimes being attributed to issues like missing an API key. Another challenge we faced this week was improving the user experience since, while we were nearly done with the user features we implemented, we were experimenting with user scenarios end-to-end and found small bugs (i.e. UI not being what we expected, edge cases where our features did not work). Finally, our team struggled with creating the right demo flow in preparation for our demo this week and next week. Since we implemented multiple features, it was hard to consolidate these features in a cohesive presentation that could fit in the time frame we were given. However, by regularly practicing, we were able to create a demo presentation that we could be proud of. 

* Did you finish all of your tasks in your sprint plan for this week? If you did not finish all of the planned tasks, how would you prioritize the remaining tasks on your list?  (i.e over planned, did not know how to implement certain features, miscommunication from the team, had to pivot from original plans, etc.)

We finished nearly all of the features we wanted to create, including the ability to search for users, integrating Google authentication, exporting itinerary through email, and the ability to edit itineraries. We however did not implement our two stretch features which included the ability to edit itineraries through an AI chatbot, giving users to ability to provide custom tags, and finally giving users to provide custom locations. This mainly was since we were very ambitious with all of our features, especially because we were assisted with AI. Ultimately, we decided to focus moreso on the user experience and having a complete app rather than rushing out features when at the end of the week. 

* Did the resources provided to you help prepare you in planning and executing your capstone project sprint this week? Be specific, what resources did you find particularly helpful or which tasks did you need more support on?

We very much appreciated the Bug Bag because we got to see how other users experienced our app and how we could improve the app accordingly. Through our feedback, we were able to change our user experience so the application was more cohesive and we were able to account for more edge cases. We also appreciated the support we got from our advisors, managers, and mentors since they helped us consider each user scenarios and consider how we can approach the final features we planned on implemented. 

* Which features and user stories would you consider “at risk”? How will you change your plan if those items remain “at risk”?
Since this is the last Sprint, we have finished all of the features and user stories. While we had to cut certain features for the sake of the time, each of the features we did implement are fully tested end-to-end and hence none of our features are "at risk" now.
